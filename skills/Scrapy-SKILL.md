# 小说网站爬取分析器

## 概述

这是一个专门用于分析小说网站结构的 Skill，能够自动识别和提取小说网站的关键元素，包括目录页、章节列表、正文内容、翻页逻辑、导航链接等，最终输出一份完整的爬取规范 Markdown 文件。

## 触发场景

当用户提到以下内容时，应主动使用此 Skill：
- "分析这个小说网站"
- "帮我爬取这个小说"
- "这个网站的章节结构是什么"
- "生成小说爬虫配置"
- "分析小说目录页"
- "提取小说正文结构"
- "识别翻页逻辑"
- 用户提供的 URL 明显是小说阅读网站

## 分析维度

### 1. 网站类型识别

首先判断网站类型，常见的小说网站类型：

| 类型 | 特征 | 示例 |
|------|------|------|
| 传统目录型 | 有明确的目录页，章节列表清晰 | 起点中文网、纵横中文网 |
| 阅读页型 | 直接进入阅读页，需要找目录 | 某些盗版小说站 |
| 分页型 | 正文分多页显示 | 一些老式小说站 |
| 滚动加载型 | 滚动加载更多章节 | 一些移动端适配站 |
| 反爬型 | 需要登录/验证码 | 某些付费章节 |

### 2. 目录页分析

需要提取的信息：

- **目录页 URL 模式**：识别目录页的 URL 结构
- **章节列表选择器**：CSS 选择器或 XPath
- **章节链接提取规则**：如何从列表中提取章节 URL
- **章节标题提取规则**：章节名称的获取方式
- **章节序号提取**：是否有章节编号
- **最新章节标记**：是否有更新时间、最新章节提示
- **分页机制**：目录是否有分页

**常见目录结构模式**：

```html
<!-- 模式1：简单列表 -->
<div class="chapter-list">
  <a href="/chapter/1">第一章 开端</a>
  <a href="/chapter/2">第二章 相遇</a>
</div>

<!-- 模式2：有序列表 -->
<ol class="catalog">
  <li><a href="1.html">第1章</a></li>
  <li><a href="2.html">第2章</a></li>
</ol>

<!-- 模式3：分组结构 -->
<div class="volume">
  <h3>第一卷</h3>
  <div class="chapters">
    <a href="/v1/c1">章节...</a>
  </div>
</div>
```

### 3. 章节页分析

需要提取的信息：

- **章节标题选择器**：标题的 CSS 选择器
- **正文内容选择器**：正文的 CSS 选择器
- **正文容器识别**：如何定位正文区域
- **广告/干扰元素**：需要过滤的元素
- **章节元数据**：字数、更新时间、作者信息等

**常见章节页结构**：

```html
<!-- 模式1：标准结构 -->
<h1 class="title">第一章 开端</h1>
<div class="content" id="chapter-content">
  <p>正文内容...</p>
</div>

<!-- 模式2：分离式结构 -->
<div class="chapter-header">
  <span class="chapter-num">第1章</span>
  <span class="chapter-title">开端</span>
</div>
<div class="text-content">
  正文内容...
</div>
```

### 4. 正文完整性分析

检查以下内容：

- **正文是否截断**：是否有"本章未完"、"点击下一页继续"
- **分页标记识别**：页码导航、下一页链接
- **付费内容标记**：是否有 VIP 章节、付费提示
- **反爬内容**：乱码、加密文本、图片验证
- **广告混入**：正文中的广告文字需要过滤

**需要识别的分页模式**：

```html
<!-- 模式1：页码导航 -->
<div class="page-nav">
  <a href="1.html">上一页</a>
  <span>1/3</span>
  <a href="3.html">下一页</a>
</div>

<!-- 模式2：点击继续 -->
<div class="next-page">
  <a href="next.html">点击继续阅读</a>
</div>

<!-- 模式3：章节内分页 -->
<div class="pagination">
  <a class="prev" href="?page=1">←</a>
  <a class="next" href="?page=3">→</a>
</div>
```

### 5. 导航链接分析

需要提取的导航元素：

| 导航元素 | 用途 | 常见选择器 |
|----------|------|-----------|
| 上一章 | 顺序爬取 | `a.prev-chapter`, `.prev a`, `a:contains('上一章')` |
| 下一章 | 顺序爬取 | `a.next-chapter`, `.next a`, `a:contains('下一章')` |
| 返回目录 | 获取完整列表 | `a.back-catalog`, `.return a`, `a:contains('目录')` |
| 上一页 | 正文分页 | `a.prev-page`, `.page-prev` |
| 下一页 | 正文分页 | `a.next-page`, `.page-next` |

### 6. 反爬机制识别

需要识别的反爬手段：

- **User-Agent 检测**：需要伪装浏览器
- **Referer 检测**：需要设置来源页
- **Cookie 验证**：需要保存会话
- **访问频率限制**：需要添加延迟
- **JavaScript 渲染**：需要使用浏览器渲染
- **验证码**：需要人工介入或 OCR
- **加密内容**：需要解密脚本

## 执行指令

当用户请求分析小说网站时，按以下步骤执行：

### 步骤 1：接收并验证 URL
- 确认用户提供了有效的 URL
- 如果未提供 URL，提示用户提供

### 步骤 2：访问页面并分析结构
- 使用 Browser Automation 或 WebFetch 访问页面
- 获取 HTML 结构
- 识别网站类型

### 步骤 3：多页面分析
- 如果是目录页，分析目录结构
- 如果是章节页，分析章节结构并尝试访问目录页
- 如果是正文页，分析正文结构并检查分页

### 步骤 4：提取关键元素
按照"分析维度"中的各项逐一提取：
- 目录选择器
- 章节标题选择器
- 正文选择器
- 导航链接选择器
- 反爬机制

### 步骤 5：验证与测试
- 验证选择器的准确性
- 测试导航链接的正确性
- 检查正文是否完整

### 步骤 6：生成规范文件
按照"输出规范"生成完整的 MD 文件，保存到用户工作目录。

## 注意事项

1. **遵守 robots.txt**：在爬取前检查网站的 robots.txt
2. **合理延迟**：避免对目标网站造成压力
3. **版权意识**：提醒用户注意版权问题
4. **内容验证**：确保提取的内容是有效的小说正文，而非广告或错误信息
5. **编码处理**：注意不同网站的字符编码（GBK、UTF-8 等）
